# SeedHedge v0.4.5 — Final Farmer Journey Candidate (release gated)

## Purpose
Keep the underlying existing TypeScript seed/acreage/cost and rainfall/exposure engine unchanged, while simplifying the farmer's day-to-day interface. This is **not** the other application's Python engine and does not introduce Python backend calculations.

## Default main path

1. **Check Weather:** select the region and real 2022–2025 historical ERA5 reanalysis or clearly fictional practice data; read loading/failure status; optionally view current 7-day forecast (separate context, not used to decide historical plans).
2. **Enter Farm Details:** soybean-only, acres, 2024 replay window, date spacing, select candidate dates and editable cost rates.
3. **Check My Plan:** simple Plan A rainfall pass counts by date, expandable year-by-year source values, and Plan B's best passing one-visit/two-visit alternatives. Adjustable threshold and exploratory split do not alter the computed winner.
4. **See My Action Plan:** explicit modeled suggestion, explanation of agreement/disagreement between A and B, next steps; farm summary, per-date past rain/temperature/index, provenance links, print/PDF, locally installed voice fallback and grounded FAQ.

The separate **Detailed View** preserves the prior v0.4.4 dashboard and analytical controls for the judges. It uses technical English wording; the farmer path is translated into English, Marathi and Hindi. Local-language testing on real hardware remains necessary.

## Scientific boundaries
- This compares historical 2024 target dates using 2022–2025 retrospective weather observations. It does not issue present-day sowing predictions, field-level soil analysis, certified risk probability, profit or yield estimates.
- Plan A picks the first date meeting a selected 14-day rainfall threshold in **all** four replay years. Plan B ranks model-passing allocations by the existing cost formula. They are *different experimental rules*. When they disagree, the interface says so rather than inventing evidence that one is safer.
- For incomplete real weather, no historical conclusion is issued. Practice-mode outcomes are clearly flagged as fictional; rain charts of observed data stay hidden.
- INR costs are computed from the farm acreage and editable example rates; they are not fixed or independently verified market quotes.
- Source URLs shown in the report are generated by the existing weather request code, not invented links.
