# SeedHedge v0.4 — 90-second judge demo (script/storyboard)

**0–12s: The farmer.** Display the case-study panel. “This is a two-acre soybean farmer in Akola comparing historical sowing dates under uncertain monsoon conditions. We do not claim today's farm recommendations.”

**12–30s: Two independent approaches.** Show Plan A's preceding-14-day rainfall rule (editable 100 mm threshold) beside Plan B's modeled exposure and staggered allocations. Explain that both share the same farm size and cost rates but *not* the same decision rule.

**30–48s: Evidence.** Show Open-Meteo reanalysis provenance and one 2024 rainfall chart. Expand the diagnostics table and briefly identify the unvalidated weights and 0.60 model screen.

**48–64s: Sensitivity.** Change Plan A's threshold; then select a 70/30 split for Plan B. Edit mobilization cost. Read the updated cost delta, without claiming reduced crop loss.

**64–78s: Resilience.** Switch explicitly to Synthetic UI demo, click Stress then Stable. State the active scenario and observe any changed exposure or pass count. Point out Plan A says unavailable when only synthetic evidence is selected.

**78–90s: Conclusion.** “We provide transparent, cost-aware counterfactual comparisons—no invented live evidence and no crop-safety certification. Next steps are agronomist review and outcome-based validation.”
